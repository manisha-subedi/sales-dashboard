Four years of Superstore sales

Superstore is a made-up office supplies company that ships in Tableau as sample data. It has 10,194 order lines, 5,111 orders, and 804 customers, from January 2023 to December 2026.

I built a Tableau dashboard on it, and this page shows the same numbers as plain charts, plus a small tool that tries a cap on discounts.

What if discounts were capped?

Pick a cap. Every line with a bigger discount is recomputed as if it had the capped discount instead. Cost stays the same, so the extra revenue goes straight to profit.

This assumes the customers would still have bought at the smaller discount, which is not certain. It shows how much money the big discounts cost, not a forecast of what a new policy would earn.

How I built this

The source is one Excel file with three sheets: orders, returns, and regional managers. DuckDB SQL turns it into a small star schema: one fact table with an order line per row, and dimensions for customers, products, and dates. Returns and managers are joined onto the fact.

Two things in the source needed care. 32 product ids carry two different names, so the product table keeps the name that appears most often and counts the names. The returns sheet lists some orders twice, so it is deduplicated before the join. Tests check both, plus the row counts, the keys, and the growth numbers.

The build writes JSON files that this page reads to draw the charts and run the discount tool. It also writes one flat CSV that the Tableau workbook connects to. The code, SQL, tests, and the Tableau guide are on GitHub.
