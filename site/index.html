Four years of Superstore sales

This project uses Tableau's Superstore sample data, which represents a fictional retailer. It covers 10,194 order lines, 5,111 orders and 804 customers from January 2023 to December 2026.

I used SQL to prepare the data and built a three-page Tableau report. Below the report, you can explore the results and see how a limit on discounts would affect profit under fixed assumptions.

The Tableau dashboard

The report has three pages: Overview, Customers and Products. Use the controls to change the year or filter by region and customer segment. On Overview, click a cell in the segment and category chart to filter the other charts on that page.

What if we limited discounts?

Choose a maximum discount. The calculator applies that limit to order lines with a higher discount, then recalculates sales and profit. It keeps costs and quantities unchanged.

This assumes customers would buy the same quantities at a higher price. Some might buy less or not buy at all. The result is a comparison under these assumptions, not a profit forecast.

How I built this

The source Excel file has three sheets: orders, returns and regional managers. I used DuckDB and SQL to create a sales table with one row per order line and separate tables for customers, products and dates. I then joined the return records and manager details to the sales table.

The source has 32 product IDs with more than one name. For each ID, I kept the most common name and recorded how many names appeared. I also removed duplicate return records before joining them to sales. Tests check these steps, row counts, table keys and growth figures.

The build script exports JSON files for this page and a CSV for Tableau, so both use the same prepared data. The code, SQL, tests and Tableau guide are on GitHub.
